## 商品创建/编辑

**路由：**
- 创建：`/admin/products/create`
- 编辑：`/admin/products/:id/edit`

**对应页面：** `AdminProductCreate.vue`

### 表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 中文名称 | 文本 | 是 | 商品中文名 |
| 英文名称 | 文本 | 是 | 商品英文名 |
| SKU | 文本 | 是 | 商品编码 |
| 分类 | 下拉选择 | 是 | 所属分类 |
| 品牌 | 文本 | 否 | 品牌名称 |
| 原价 (GHS) | 数字 | 是 | 销售价格 |
| 划线价 | 数字 | 否 | 折扣前价格 |
| 库存数量 | 数字 | 是 | 当前库存 |
| 库存预警 | 数字 | 否 | 低库存提醒阈值 |
| 重量 (kg) | 数字 | 否 | 商品重量 |
| 商品描述 | 多行文本 | 否 | 详细描述 |

### 规格参数

支持动态增删规格行：

```
┌─────────────────────────────────────┐
│  规格名称         规格值            │
│  ─────────        ─────────         │
│  材质        ──   纯棉      [删除]  │
│  颜色        ──   黑色      [删除]  │
│  [+ 添加规格]                       │
└─────────────────────────────────────┘
```

### 批量价格阶梯

支持动态增删价格阶梯行：

```
┌─────────────────────────────────────┐
│  数量区间         价格         折扣  │
│  ─────────        ──────      ────  │
│  10+          ──  ₵108.00    10%   │
│  20+          ──  ₵96.00     20%   │
│  [+ 添加价格梯度]                    │
└─────────────────────────────────────┘
```

### 表单验证

## 分类管理

**路由：** `/admin/categories`

**对应页面：** `AdminCategories.vue`

### 功能概述

| 功能 | 说明 | 状态 |
|------|------|------|
| 分类树形展示 | 多级分类树形结构 | ✅ 已完成 |
| 分类统计 | 总分类数、启用数、停用数 | ✅ 已完成 |
| 新增分类 | 添加顶级分类 | ✅ 已完成 |
| 新增子分类 | 在指定分类下添加子分类 | ✅ 已完成 |
| 编辑分类 | 修改分类信息 | ✅ 已完成 |
| 删除分类 | 删除指定分类 | ✅ 已完成 |
| 启用/停用 | 切换分类状态 | ✅ 已完成 |
| 拖拽排序 | 调整分类排序 | ✅ 已完成 |

### 分类数据结构

```typescript
interface CategoryNode {
  id: string
  nameZh: string           // 中文名称
  nameEn: string           // 英文名称
  status: 'active' | 'inactive'
  sort: number             // 排序值
  icon: string             // 图标
  productCount: number     // 商品数量
  children: CategoryNode[] // 子分类
}
```

### 编辑表单

| 字段 | 说明 |
|------|------|
| 中文名称 | 分类中文显示名 |
| 英文名称 | 分类英文显示名 |
| 排序 | 数字越小越靠前 |
| 上级分类 | 选择父分类（留空为顶级） |
| 状态 | 启用/停用 |
