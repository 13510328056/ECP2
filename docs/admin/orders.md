# 订单管理

## 订单列表

**路由：** `/admin/orders`

**对应页面：** `AdminOrders.vue`

### 功能概述

| 功能 | 说明 | 状态 |
|------|------|------|
| 订单列表 | 展示所有订单（编号、客户、金额、状态） | ✅ 已完成 |
| 状态筛选标签 | 全部/待付款/待发货/已发货/已完成 | ✅ 已完成 |
| 关键词搜索 | 按订单号、客户名、电话搜索 | ✅ 已完成 |
| 日期筛选 | 按起止日期范围筛选 | ✅ 已完成 |
| 点击查看详情 | 跳转订单详情页 | ✅ 已完成 |

### 状态筛选标签

| 标签 | 筛选条件 | 说明 |
|------|---------|------|
| 全部 | all | 显示所有订单 |
| 待付款 | pending_payment | 等待客户支付 |
| 待发货 | pending/paid | 已支付等待发货 |
| 已发货 | shipped | 已发货运输中 |
| 已完成 | completed | 已完成订单 |

### 订单列表信息

每条订单显示：
- 订单号（如 GH88293401）
- 客户姓名
- 联系电话
- 城市
- 商品数量
- 订单总金额
- 状态标签（带颜色区分）
- 商品缩略图

## 订单详情

**路由：** `/admin/orders/:id`

**对应页面：** `AdminOrderDetail.vue`

### 功能概述

| 功能 | 说明 | 状态 |
|------|------|------|
| 订单基本信息 | 订单号、创建时间、支付方式、交易号 | ✅ 已完成 |
| 状态信息卡片 | 当前状态标题、描述、状态颜色 | ✅ 已完成 |
| 客户信息 | 姓名、电话、详细地址 | ✅ 已完成 |
| 商品列表 | 商品名、SKU、数量、单价 | ✅ 已完成 |
| 金额明细 | 小计、运费、折扣、总计 | ✅ 已完成 |
| 物流信息 | 物流公司、运单号、预计送达 | ✅ 已完成 |
| 物流录入 | 填写物流公司、运单号 | ✅ 已完成 |
| 状态操作 | 确认订单、标记发货、完成订单 | ✅ 已完成 |
| 备注 | 订单备注显示 | ✅ 已完成 |

### 状态操作按钮

根据当前状态显示不同的操作按钮：

| 当前状态 | 可用操作 | 操作后状态 |
|---------|---------|-----------|
| 待付款 (pending_payment) | 确认订单 | paid |
| 已支付 (paid) | 确认发货 | shipped |
| 配货中 (processing) | 确认发货 | shipped |
| 已发货 (shipped) | 完成订单 | completed |

### 状态颜色标识

| 状态 | 颜色 |
|------|------|
| 待付款 | 黄色 (bg-yellow-500) |
| 已支付 | 蓝色 (bg-blue-500) |
| 待发货 | 绿色 (bg-[#006B3F]) |
| 配货中 | 深蓝 (bg-blue-600) |
| 已发货 | 青色 (bg-cyan-600) |
| 已完成 | 绿色 (bg-green-600) |
| 已取消 | 灰色 (bg-gray-500) |
