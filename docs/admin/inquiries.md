# 询盘管理

## 询盘列表

**路由：** `/admin/inquiries`

**对应页面：** `AdminInquiries.vue`

### 功能概述

| 功能 | 说明 | 状态 |
|------|------|------|
| 询盘列表 | 展示所有客户询盘 | ✅ 已完成 |
| 状态筛选标签 | 全部/待回复/处理中/已报价/已关闭 | ✅ 已完成 |
| 关键词搜索 | 按客户名、电话、消息内容搜索 | ✅ 已完成 |
| 状态计数 | 各状态标签显示数量 | ✅ 已完成 |
| 点击查看详情 | 跳转询盘详情页 | ✅ 已完成 |

### 状态筛选标签

| 标签 | 状态值 | 颜色 |
|------|--------|------|
| 全部 | all | — |
| 待回复 | new | 橙色 |
| 处理中 | contacted | 蓝色 |
| 已报价 | resolved | 绿色 |
| 已关闭 | closed | 灰色 |

### 列表展示信息

每条询盘显示：
- 客户姓名
- 联系电话
- 询盘主题
- 需求描述（截断显示）
- 状态标签
- 创建时间

### 搜索功能

支持按以下字段搜索：
- 客户姓名
- 联系电话
- 消息内容
- 产品型号

## 询盘详情

**路由：** `/admin/inquiries/:id`

**对应页面：** `AdminInquiryDetail.vue`

### 功能概述

| 功能 | 说明 | 状态 |
|------|------|------|
| 客户信息 | 姓名、邮箱、电话 | ✅ 已完成 |
| 询盘主题 | 显示询盘主题类型 | ✅ 已完成 |
| 产品型号 | 客户感兴趣的产品 | ✅ 已完成 |
| 需求描述 | 客户详细需求 | ✅ 已完成 |
| 状态管理 | 更新询盘处理状态 | ✅ 已完成 |
| 回复记录 | 显示沟通历史记录 | ✅ 已完成 |
| 回复方式选择 | WhatsApp/邮件/电话 | ✅ 已完成 |
| 回复内容编辑 | 输入回复文本 | ✅ 已完成 |
| 发送回复 | 记录回复并更新状态 | ✅ 已完成 |

### 询盘主题映射

| 英文标识 | 中文显示 |
|---------|---------|
| general | 一般咨询 |
| product | 产品咨询 |
| bulk_order | 批量询价 |
| custom | 定制需求 |
| other | 其他 |

### 状态更新

管理员可手动更新询盘状态：

```
新询盘 (new) → 处理中 (contacted) → 已报价 (resolved) → 已关闭 (closed)
```

### 回复功能

```
┌─────────────────────────────────────────┐
│  回复方式:                               │
│  ○ WhatsApp  ○ 邮件  ○ 电话              │
│                                         │
│  回复内容:                               │
│  ┌─────────────────────────────────────┐│
│  │                                     ││
│  │                                     ││
│  └─────────────────────────────────────┘│
│                                         │
│  [发送回复]                              │
└─────────────────────────────────────────┘
```

### 回复记录时间线

每条回复记录显示：
- 回复类型（已收到/已回复）
- 回复内容
- 回复方式（WhatsApp/邮件/电话）
- 时间戳
