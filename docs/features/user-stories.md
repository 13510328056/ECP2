## 用户旅程概览

### 买家购物旅程

```
浏览商品 → 查看详情 → 加入购物车 → 结算 → 支付 → 订单确认 → 等待配送 → 收货完成
```

访问路径：`/` → `/products` → `/product/:id` → `/cart` → `/checkout` → `/payment` → `/order-confirmation` → `/order/:id`

### 询盘转化旅程

```
填写表单 → 选择主题 → 提交询盘 → 系统通知客服 → 客服回复 → 报价跟进 → 转化订单
```

访问路径：`/contact` → 表单提交 → 存储到 localStorage → Admin查看

### 后台管理旅程

```
管理员登录 → 数据看板 → 管理模块处理
```

访问路径：`/admin/login` → `/admin/dashboard` → 各管理模块
