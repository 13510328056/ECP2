# 多语言支持

## 技术选型

使用 **Vue I18n v10**（Composition API 模式）实现国际化支持。

### 初始化配置

```typescript
// src/i18n/index.ts
import { createI18n } from 'vue-i18n'
import en from './en.json'
import zh from './zh.json'

export const i18n = createI18n({
  legacy: false,        // 使用 Composition API 模式
  locale: 'zh',         // 默认语言：中文
  fallbackLocale: 'zh', // 回退语言：中文
  messages: { en, zh },
})
```

### 在 main.ts 中注册

```typescript
// src/main.ts
import { i18n } from './i18n'
app.use(i18n)
```

## 语言状态管理

### Language Store

```typescript
// src/stores/language.ts
import { defineStore } from 'pinia'

export type SupportedLocale = 'zh' | 'en'

export const useLanguageStore = defineStore('language', () => {
  const locale = ref<SupportedLocale>('zh')

  function setLocale(lang: SupportedLocale) {
    locale.value = lang
  }

  function toggleLocale() {
    locale.value = locale.value === 'zh' ? 'en' : 'zh'
  }

  return { locale, setLocale, toggleLocale }
})
```

### 语言持久化

通过 `pinia-plugin-persistedstate` 插件自动持久化语言选择。

```typescript
// src/main.ts
pinia.use(piniaPersistedstate)
```

用户切换语言后，刷新页面时语言设置保持。

## HTML lang 属性同步

在 `App.vue` 中监听语言变化，同步更新 `<html>` 标签的 `lang` 属性：

```typescript
// src/App.vue
watch(
  () => languageStore.locale,
  (locale) => {
    document.documentElement.setAttribute('lang', locale)
  },
  { immediate: true },
)
```

## 模板中使用

```vue
<script setup>
import { useI18n } from 'vue-i18n'
const { t } = useI18n()
</script>

<template>
  <h1>{{ t('home.categoriesTitle') }}</h1>
</template>
```

## 商品双语数据

商品模型支持中英文双字段：

```typescript
interface Product {
  name: string           // 英文名称
  nameZh: string         // 中文名称
  description: string    // 英文描述
  descriptionZh: string  // 中文描述
  category: string       // 英文分类
  categoryZh: string     // 中文分类
  specifications: Record<string, string>    // 英文规格
  specificationsZh: Record<string, string>  // 中文规格
}
```

**展示逻辑：**

```typescript
const langStore = useLanguageStore()
const displayName = computed(() =>
  langStore.locale === 'en' ? product.name : product.nameZh
)
```
