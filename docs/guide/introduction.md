# ECP2 项目简介

## 项目背景

**ECP2** 是 "Li's Industrial Supplies & Services Market" 的缩写，是一个面向加纳市场的工业用品 B2B2C 电商平台。项目旨在构建行业专属采购渠道，结合线上展示与线下服务，降低采购成本并提升采购转化率。

平台提供矿产机械、劳保耗材、备件和专业配套服务，服务对象包括终端用户、SME企业采购人以及二级代理商，支持企业采购、批量报价和本地化支付。

## 项目类型

**全新开发** — 从零开始构建完整的电商前端系统，适配移动优先和B2B采购场景。

## 核心价值主张

> "Your Trusted Partner for Industrial Equipment & Safety Supplies in Ghana — Quality Machinery, Reliable Service, Local Payment Support"

## 目标用户

| 用户类型 | 说明 |
|---------|------|
| 个人买家 | 小型维修团队、现场作业人员、个体采购者 |
| 中小企业/工程承包商 | 项目经理、采购主管、维修主管 |
| 二级代理商与分销商 | 批量采购、备货、代理分销 |
| 在加纳的华人商户 | 华人工程承包商、进口代理、贸易公司 |
| 内部运营人员 | 商品运营、客服、仓储、财务 |

## 典型用户画像

| 画像 | 需求特点 |
|------|---------|
| **矿场采购经理** | 需要耐用设备、关注库存、付款方式和交付周期 |
| **华人工程负责人** | 需要中文/英文支持、快速报价、可靠本地服务 |
| **小型维修商** | 价格敏感，需要快速下单与WhatsApp即时咨询 |
| **代理商** | 关注批量价格、折扣、账期和代理支持 |
| **浏览访客** | 先比较规格与价格，再通过询盘或本地联系方式转化 |

## 系统角色体系

### 前台用户角色

| 角色 | 说明 | 权限范围 |
|------|------|---------|
| 访客 (Guest) | 未登录的网站访问者 | 浏览商品、查看价格、搜索筛选、查看评价、查看配送信息 |
| 注册用户 | 完成注册的网站用户 | 访客所有权限 + 下单购买、订单管理、询盘提交、收藏商品 |

### 后台管理角色

| 角色 | 说明 |
|------|------|
| 超级管理员 (super_admin) | 系统全功能管理 |
| 商品管理员 (product_manager) | 商品上下架、分类管理 |
| 客服 (customer_service) | 询盘回复、客户沟通 |
| 仓储 (warehouse) | 库存管理、发货处理 |
| 财务 (finance) | 订单对账、退款处理 |

## MVP 功能范围

1. **商品展示功能（前台）** — 产品分类导航、商品网格展示、商品详情页、搜索和筛选功能
2. **购物车与订单系统（前台）** — 加入购物车、购物车管理、结算流程、订单确认页、批量采购提示与起订量显示
3. **在线留言/询盘功能（前台）** — 询盘表单、附件上传、状态跟进、24小时内联系承诺
4. **多语言支持（前台）** — 中英文切换、双语内容展示、本地化展示、语言持久化存储
5. **后台管理系统（后台）** — 管理员登录认证、商品管理、订单管理、询盘管理、数据统计
